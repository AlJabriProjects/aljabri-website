Complete Equipment Line

Industry-leading crushing and screening machinery solutions

JAW CRUSHER

The Jaw Crusher is a primary crushing machine designed for crushing hard stones and granite into smaller pieces. Features include:

✓ Heavy-duty compression force
✓ Two movable jaws for crushing
✓ High efficiency and reliability
✓ Suitable for hard stone crushing
✓ Ideal for primary crushing stage

IMPACT CRUSHER

The Impact Crusher uses powerful crushing forces through rapid impact. Features include:

✓ Superior particle shape
✓ Reduced operating costs
✓ Suitable for secondary crushing
✓ Ideal for aggregate production
✓ Can be HSI or VSI configuration

VSI MACHINE

The VSI (Vertical Shaft Impact) Machine produces high-quality manufactured sand. Features include:

✓ High-speed rotation
✓ Manufactured sand production
✓ Aggregate shaping
✓ Recycling applications
✓ Excellent product quality

VIBRATING SCREENS

Vibrating Screens provide accurate material separation into multiple sizes. Features include:

✓ Multiple screening surfaces
✓ Accurate size separation
✓ High efficiency rating
✓ Customizable screen sizes
✓ Essential for quality control

CONVEYOR BELTS

Industrial conveyor systems for material transportation. Features include:

✓ Safe material handling

✓ Various speed options
✓ Durable construction
✓ Customizable configurations
